Privacy Policy

Extension: Convert MOV to MP4
Last updated: September 16, 2026

1. Overview

Convert MOV to MP4 is a Chrome browser extension that converts video files between the MOV and MP4 containers directly inside your browser. This privacy policy describes what data we collect, how we use it, how it is stored, and with whom it is shared.

2. Data We Collect

Your video content never leaves your device. The extension opens a single tab, and all conversion (remuxing or transcoding) happens locally in your browser using the WebCodecs API and the open-source Mediabunny library. Video files are never uploaded to us or to any third party.

  • Video files: Read locally from disk (via drag-and-drop or the file picker), converted locally, and either downloaded to your Downloads folder or streamed to a location you choose. We never see, receive, or store your files.
  • Anonymous installation ID: A random identifier (UUID) is generated when the extension is installed and stored locally in your browser. It is sent with the usage events below so we can tell one installation from another. It contains no personal information and is not linked to any account, email, or profile.
  • Usage events: We record anonymous events describing how the extension is used: installation, daily activity check-in, uninstallation, opening the onboarding page, dropping a file, starting a batch, starting a conversion (and which conversion path was used — instant copy or re-encode), a conversion finishing or failing, and clicking the star rating. Events include the extension version and browser language. We never send file names, file contents, or any information about what's inside your video.
  • IP address: Our backend server briefly uses your IP address (received automatically with any network request) to derive your country, then discards it — the IP itself is never written to disk or stored anywhere. Only the resulting country code is kept, for aggregate install/usage counts by country.
  • Star rating and feedback (optional): If you rate the extension 4-5 stars, we open the Chrome Web Store review page in a new tab; nothing else is sent. If you rate it 1-3 stars, an optional comment box lets you tell us what went wrong — the rating and your message (if you write one) are sent to our backend. No email or other personal identifier is collected.
  • Uninstall survey (optional): When you remove the extension, a page may open where you can select a reason and add a comment. Submitting it is voluntary; if you close the page without selecting a reason, nothing further is sent.

3. How We Use Your Data

  • Usage events and the installation ID are used only in aggregate, to see whether the extension is actually being used, where people get stuck (for example, an unusual number of conversion failures), and which features matter. They are never used to build a profile of you or to track you across websites or other extensions.
  • Feedback and uninstall reasons are used to fix bugs and prioritize improvements.
  • Country (derived from IP, IP itself discarded) is used only for aggregate installs-by-country counts.
  • We do not use any collected data for advertising, behavioral tracking, or sale to third parties.

4. Data Storage and Retention

  • Local storage: Your installation ID is stored in your browser using Chrome local storage and stays on your device until you remove the extension.
  • Our backend server: Usage events, feedback, and uninstall reasons are kept in aggregate logs on our own server (not a third-party analytics provider) and are not tied to any personal identifier.

5. Data Sharing

We do not sell, rent, or share any collected data with advertising networks, data brokers, or any other third party. The only outbound navigation the extension ever triggers on your behalf is opening the Chrome Web Store review page in a new tab if you choose to rate 4-5 stars — governed by Google's privacy policy.

6. Permissions

  • storage: To keep the anonymous installation ID on your device.
  • alarms: To send a once-a-day activity check-in, used only to estimate how many people actively use the extension.
  • Host permission (devexthub.com): To send the anonymous usage events described above to our own backend.

7. Data Security

All data sent to our backend is transmitted over encrypted HTTPS. We do not use any third-party analytics or advertising SDKs.

8. Your Rights

Since we do not collect personally identifiable information, clearing your browser's local storage for this extension (or simply removing the extension) removes the local installation ID. For any data requests, contact us at the address below.
